# Ручная идентификация модели IPDT по тренду

Методика для **интегрирующего звена с запаздыванием** (IPDT):

```
G(s) = Ka · e^(−τ·s) / s        ⟺        d(уровень)/dt = Ka · CV(t − τ)
```

Применяется, когда нужно определить параметры модели **вручную** из
записи тренда SCADA (без запуска автоматической идентификации в
приложении) либо для того, чтобы проверить результаты авто-идентификации.

---

## 1. Что такое IPDT и Ka

- **IPDT** — интегрирующий объект без самовыравнивания (уровень,
  давление в ёмкости, объём в резервуаре). Его выход **не останавливается**
  — при постоянном ненулевом ходе насоса он непрерывно ползёт.
- **Ka** — интегральный коэффициент усиления: **скорость** изменения
  выхода на 1 % хода насоса. Единицы — `%уровня/с` на `%CV`, т.е. `1/с`.
- В отличие от FOPDT, здесь **нет статического K**. «Усиление» IPDT — это
  именно `Ka` (скорость), а не остановившееся значение.

> В приложении поле так и называется: **«Ka (усиление интегрир.), 1/с»**.

---

## 2. Формулы (метод «изменения наклона»)

Уровень до ступеньки **не обязан стоять** — он может дрейфовать
с постоянным «начальным углом» `m₀`. В этом случае:

```
ΔCV  = CV₁ − CV₀                     — величина ступеньки насоса
m₀   = наклон линии ПВ до ступеньки  — «начальный угол» (может быть ≠ 0)
m₁   = наклон линии ПВ после ступеньки
Ka   = (m₁ − m₀) / ΔCV
τ    = t_пересечения прямых − t_ступеньки
```

Точка **пересечения** продолжений двух линий (`m₀` и `m₁`) — это момент,
где реально проявилось влияние ступеньки; от него отсчитывается `τ`.

При `m₀ ≈ 0` (уровень почти стоял) формула сводится к классике: `Ka = m₁/ΔCV`.

---

## 3. Пошаговый ручной расчёт

Рассмотрим пример, где уровень **уже ползёт вверх** до ступеньки
(«начальный угол» ненулевой).

### 3.1. Найдите ступеньку CV

Скачок хода насоса и постоянное значение после него.

```
CV₀ = 40 %    ход насоса до ступеньки
CV₁ = 55 %    ход насоса после
ΔCV = 55 − 40 = 15 %
```

### 3.2. Оцените «начальный угол» — наклон ДО ступеньки

Возьмите линейный участок прямо **перед** скачком насоса и две точки:

```
t₀a = 5 с,   PV₀a = 44,0 %
t₀b = 9 с,   PV₀b = 50,4 %
m₀ = (50,4 − 44,0) / (9 − 5) = 6,4 / 4 = 1,60 %/с
```

> Уровень до ступеньки шёл вверх со скоростью 1,6 %/с — это и есть
> «начальный угол». Он **не** мешает расчёту.

### 3.3. Оцените наклон ПОСЛЕ ступеньки

На прямом (линейном) участке рампы после ступеньки:

```
t₁a = 30 с,  PV₁a = 80,0 %
t₁b = 50 с,  PV₁b = 112,0 %
m₁ = (112,0 − 80,0) / (50 − 30) = 32 / 20 = 1,60 %/с  ← вымышленно, см. ниже
```

> ⚠️ В примере выше наклоны совпали лишь условно. В реальности после
> ступеньки скорость меняется. Ниже — рабочий пример с реальной разницей:
> `m₀ = 1,60`, `m₁ = 2,20` (%/с).

### 3.4. Ka по изменению наклона

```
Ka = (m₁ − m₀) / ΔCV = (2,20 − 1,60) / 15 = 0,60 / 15 = 0,040  [1/с]
```

### 3.5. Запаздывание τ

Продолжите обе линии до пересечения. Пусть оно приходится на:

```
t_пересечения = 12,5 с
t_ступеньки   = 10,0 с
τ = 12,5 − 10,0 = 2,5 с
```

**Итог:** `Ka = 0,040 1/с`, `τ = 2,5 с`.

---

## 4. Определение знака Ka

- **Приток** (больше открыли насос → уровень растёт) → `Ka > 0`.
- **Дренаж** (больше насос → уровень падает) → наклон после ступеньки
  меньше, чем до → `(m₁ − m₀) < 0` → `Ka < 0`.

Знак определяется автоматически по знаку `(m₁ − m₀)` — ничего считать вручную
не нужно, кроме понимания, что получится.

### Балансный ход CV

У уровня есть **балансная точка** — ход насоса `CV`, при котором приток равен
стоку и уровень «стоит» (в примере выше ≈ 34 %). Она вычисляется автоматически:

```
balance = CV₀ − m₀ / Ka
```

Приложение использует `balance` как **начальный ход регулятора** при симуляции
(поле «CV (начальное) / баланс» на странице результатов), поэтому модель
интегрирует **отклонение** хода CV от баланса: `d(уровень)/dt = Ka·(CV − balance)`.
Это корректно работает и для прямого, и для обратного действия (дренаж).

---

## 5. Практические советы

- **Только секунды.** Если тренд в минутах — переведите в секунды, иначе
  Ka будет в 60 раз больше/меньше.
- **Берите среднюю (линейную) часть рампы** — не начало (кривизна после
  запаздывания) и не конец (уровень упирается в 100 % / клапан — линейность
  ломается).
- **Точки дальше друг от друга** → меньше влияние шума.
- **Участок до ступеньки** тоже берите линейным — если до ступеньки уже был
  изгиб, наклон `m₀` оценится неверно.
- **Ступенька ≥ 10–15 %** — чтобы изменение наклона было видно над шумом.
- **Шумный тренд** — постройте в Excel линейный тренд (даёт наклон напрямую)
  по каждому участку либо усредните несколько пар точек.
- **Проверка**: при `m₀ ≈ 0` результат должен совпасть с простым
  `Ka = m₁/ΔCV`, а `τ` — с временем от скачка до начала рампы.

---

## 6. Если нет чёткой ступеньки (замкнутый контур)

В записи **замкнутого контура** (ПИД уже крутит насос, CV меняется постоянно)
надёжно определить `m₀`/`m₁` сложно — наклоны «плавают». Рекомендуется:

1. Перевести контур в **ручной режим**.
2. Один раз ступенькой сдвинуть насос (≥ 10–15 %).
3. Записать рампу (после выхода на линейный участок).
4. Посчитать `Ka` и `τ` как выше — либо загрузить CSV в приложение:
   авто-идентификация IPDT сработает сама.

Это и есть «правильные» данные для идентификации IPDT.

---

## 7. Формат CSV и шаги в приложении

Файл с колонками `Time;PV;SP;CV` (разделитель `;`, десятичная запятая —
европейский формат; либо точка/запятая — определяется автоматически):

```
Time;PV;SP;CV
0,0;44,0;50,0;40,0
...
9,0;50,4;50,0;40,0      ← до ступеньки, уровень дрейфует (m₀ ≠ 0)
10,0;50,5;50,0;55,0     ← ступенька CV 40→55
12,5;...;50,0;55,0      ← τ: линия разгона продолжается от точки пересечения
...
```

Действия в приложении:

1. На странице загрузки в выпадающем списке **«Тип объекта»** выберите
   **IPDT — интегрирующее звено с запаздыванием**.
2. Загрузите CSV и нажмите «Загрузить и рассчитать».
3. На странице «Результаты» в карточке **Параметры модели** появятся поля
   **Ka** и **τ** — их можно при необходимости отредактировать вручную и
   пересчитать.
4. Для IPDT доступны методы настройки: **Зиглер–Николс (замкнутый), IMC,
   SIMC, ITAE** (кроме случая τ ≈ 0 — тогда только IMC/SIMC/ITAE).

> При ручном вводе: если хотите задать модель по тренду сами — просто
> впишите рассчитанные `Ka` и `τ` в поля и нажмите «Пересчитать».
