# Ручная идентификация модели FOPDT по тренду

Методика для **апериодического звена первого порядка с запаздыванием**
(FOPDT):

```
G(s) = K · e^(−τ·s) / (T·s + 1)
```

Применяется, когда нужно определить параметры модели **вручную** из
записи тренда SCADA либо проверить результаты автоматической
идентификации в приложении.

> **Внимание:** это метод для **самовыравнивающегося** объекта (печь,
> теплообменник, резервуар с уровнем под контролем оттока), где выход
> **устанавливается** на новом значении после ступеньки. Для
> интегрирующего объекта (уровень без самовыравнивания) используйте
> [инструкцию по IPDT](ipdt_manual_identification.md).

---

## 1. Что такое FOPDT и K

- **K** — статический коэффициент усиления: изменение выхода при 1 % хода
  регулятора. Единицы — `ед. PV / %CV`. Определяется по **установившемуся**
  приросту.
- **T** — постоянная времени: время, за которое выход достигает **63,2 %**
  от установившегося изменения (после запаздывания). Характеризует
  инерционность.
- **τ** — чистое запаздывание: время от ступеньки входа до начала реакции
  выхода.

---

## 2. Формулы (метод двух точек 28,3 % / 63,2 %)

```
K  = ΔPV_уст / ΔCV
T  = 1,5 · (t₆₃ − t₂₈)
τ  = (t₆₃ − t_ступеньки) − T
```

- `t₂₈` — момент, когда выход достигает **28,3 %** от установившегося
  изменения.
- `t₆₃` — момент, когда выход достигает **63,2 %** от установившегося
  изменения.

---

## 3. Пошаговый ручной расчёт

### 3.1. Найдите ступеньку CV

Скачок хода регулятора (клапана) и постоянное значение после него.

```
CV₀ = 30 %    до ступеньки
CV₁ = 45 %    после
ΔCV = 45 − 30 = 15 %
```

### 3.2. Установившееся изменение выхода

Дождитесь, пока ПВ выйдет на новое установившееся значение (медиана
хвоста участка), и зафиксируйте:

```
PV₀ = 50 ед.   до ступеньки
PV∞ = 80 ед.   установившееся после
ΔPV_уст = 80 − 50 = 30 ед.
```

### 3.3. K

```
K = ΔPV_уст / ΔCV = 30 / 15 = 2,0   [ед./%CV]
```

### 3.4. Моменты 28,3 % и 63,2 %

Вычислите уровни от начального значения:

```
Уровень28 = PV₀ + 0,283 · ΔPV_уст = 50 + 0,283·30 = 58,49 ед.
Уровень63 = PV₀ + 0,632 · ΔPV_уст = 50 + 0,632·30 = 68,96 ед.
```

Найдите по тренду времена достижения этих уровней (интерполяция между
точками):

```
t₂₈ = 18,5 с
t₆₃ = 25,0 с
t_ступеньки = 10,0 с
```

### 3.5. T и τ

```
T  = 1,5 · (t₆₃ − t₂₈) = 1,5 · (25,0 − 18,5) = 1,5 · 6,5 = 9,75 с
τ  = (t₆₃ − t_ступеньки) − T = (25,0 − 10,0) − 9,75 = 5,25 с
```

**Итог:** `K = 2,0`, `T = 9,75 с`, `τ = 5,25 с`.

---

## 4. Определение знака K

- **Прямое действие** (больше открыли клапан → выход растёт) → `K > 0`
  (`ΔPV_уст` и `ΔCV` одного знака).
- **Обратное действие** (больше ход → выход падает, например клапан
  охлаждения) → `K < 0`.

Знак берётся из знака `ΔPV_уст`. В приложении он учитывается автоматически
(бейдж «обратное действие»).

---

## 5. Практические советы

- **Только секунды** — переведите тренд из минут в секунды, иначе T и τ
  получатся неверными.
- **Установившийся хвост** — берите медиану последних ~25 % участка после
  ступеньки, чтобы не «словить» шум или начало следующего возмущения.
- **Уровни 28,3 % / 63,2 %** считаются от **начального** уровня `PV₀`,
  ищите их интерполяцией между соседними точками (не беря ближайшую).
- **Достаточно длинная запись** — чтобы процесс успел установиться; иначе
  `ΔPV_уст` занижен, а T/τ искажены.
- **Ступенька ≥ 10–15 %** — прирост выхода должен быть виден над шумом.
- **Нелинейные края** — если выход близко к пределу шкалы (упирается),
  участок кривится; отбрасывайте его.
- **Шумный тренд** — предварительно усредните/сгладьте ПВ либо визуально
  проведите плавную кривую.

---

## 6. Если нет чёткой ступеньки (замкнутый контур)

В записи **замкнутого контура** (ПИД уже работает, CV меняется постоянно)
двухточечный метод по разомкнутой характеристике неприменим — выход не даёт
чистой кривой разгона. Рекомендуется:

1. Перевести контур в **ручной режим**.
2. Один раз ступенькой сдвинуть ход регулятора (≥ 10–15 %).
3. Дождаться установившегося выхода.
4. Посчитать `K`, `T`, `τ` как выше — либо загрузить CSV в приложение.

Также для FOPDT в приложении доступны **автоматические** методы
идентификации: по переходной характеристике, аппроксимация МНК по
произвольному сигналу и релейный метод (по автоколебаниям).

---

## 7. Формат CSV и шаги в приложении

Файл с колонками `Time;PV;SP;CV` (разделитель `;`, десятичная запятая —
европейский формат; либо точка/запятая — определяется автоматически):

```
Time;PV;SP;CV
0,0;50,0;50,0;30,0
...
9,0;50,0;50,0;30,0       ← до ступеньки
10,0;50,1;50,0;45,0      ← ступенька CV 30→45
18,5;58,5;50,0;45,0      ← 28,3 % (t₂₈)
25,0;69,0;50,0;45,0      ← 63,2 % (t₆₃)
...
```

Действия в приложении:

1. На странице загрузки в выпадающем списке **«Тип объекта»** оставьте
   **FOPDT — апериодическое звено**.
2. Загрузите CSV и нажмите «Загрузить и рассчитать».
3. На странице «Результаты» в карточке **Параметры модели** появятся поля
   **K**, **T** и **τ** — их можно при необходимости отредактировать вручную
   и пересчитать.
4. Выберите метод настройки (Зиглер–Николс, Cohen–Coon, CHR, IMC, SIMC,
   AMIGO, ITAE) и тип регулятора (P/PI/PID).
