{# Справочный раздел страницы загрузки: параметры предобработки и режимы идентификации #}

Перед идентификацией данные приводятся к виду, пригодному для расчётов: интерполяция на равномерную сетку времени, подавление шума, поиск ступенчатого изменения задания.

ПараметрОписание
Шаг интерполяции, с Шаг равномерной временной сетки, на которую переносятся отсчёты. Пусто (авто) — берётся медианный интервал между соседними отсчётами времени (рекомендуется). Задание меньшего шага даёт больше точек, но не добавляет реальной информации; слишком большой шаг — огрубляет модель.
Окно медианного фильтра, точек Нечётное окно (3–15, по умолчанию 5): каждый отсчёт заменяется медианой соседних точек. Подавляет одиночные выбросы и импульсный шум датчика, почти не «смазывая» фронты переходного процесса. При высоком шуме PV окно увеличивают (7–9).
Нормализация PV/SP в 0–100 % Пересчитывает PV и SP в проценты шкалы: value / масштаб × 100. Коэффициент усиления K становится безразмерным (~1), значения Kp — привычного порядка. Масштаб берётся из строки Y-max CSV, а при её отсутствии — вводится вручную. Динамика контура (перерегулирование, время регулирования) не меняется — только представление. Подробнее на странице результатов.

Все режимы определяют параметры FOPDT (K, T, τ) и, где возможно, критические параметры Ku/Tu. После загрузки идентификацию можно повторить другим режимом — параметры модели обновятся.

РежимКогда применять
Автоматически Сначала пробуется метод переходной характеристики; если он не даёт качественного результата — автоматически выполняется аппроксимация МНК по всему сигналу. Универсальный режим по умолчанию.
По переходной характеристике Классический тест: в записи есть чёткая ступенька выхода регулятора CV (в ручном режиме) или задания SP. Метод двух точек: T и τ по моментам достижения 28,3 % и 63,2 % от установившегося изменения PV. Точно и быстро, но требует «чистой» ступеньки без наложенных возмущений.
Аппроксимация FOPDT (МНК) Наименьшие квадраты по всей записи произвольного сигнала (scipy.optimize.curve_fit, мультистарт). Работает и по замкнутому контуру, и при плавных изменениях CV, когда чистой ступеньки нет. Оценка качества — R² на странице результатов.
Релейный метод Для записей с автоколебаниями (релейное/позиционное регулирование). По амплитудам PV и CV и периоду колебаний даёт критические Ku и Tu: Ku = 4·d/(π·a), Tu = период. Используется методом Зиглера–Николса по замкнутому контуру.
