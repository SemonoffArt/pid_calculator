# ПИД-калькулятор

Веб-приложение на Flask для автоматической настройки коэффициентов
ПИД-регулятора по загруженным данным технологического процесса (CSV).

## Возможности

- Загрузка CSV (`;` — разделитель, `,` — десятичный разделитель):
  - простой формат: колонки `PV`, `SP`, `CV`, опционально `Time` (число);
  - экспорт SCADA/АСУ ТП: первая колонка — дата-время
    (`26.08.2026 3:28:00` и т.п.), заголовок — теги каналов
    (сопоставление по порядку: 2-я колонка PV, 3-я SP, 4-я CV),
    служебные строки `Y-Max`/`Y-Min` пропускаются автоматически.
    Кодировки: UTF-8 или CP1251.
- Предобработка: интерполяция на равномерную сетку, медианная фильтрация,
  обнаружение ступенчатого изменения SP.
- Идентификация модели объекта FOPDT (K, T, τ):
  - метод двух точек по переходной характеристике;
  - аппроксимация МНК по произвольному сигналу;
  - релейный метод (Ku, Tu по автоколебаниям);
  - оценка критических параметров Ku/Tu из модели.
- Методы настройки: Зиглер–Николс (открытый/закрытый контур),
  Чен–Хрон (0 % / 20 % перерегулирования), IMC (с параметром λ),
  оптимизация ITAE. Типы регуляторов: P, PI, PID (с фильтром D).
- Интерактивные графики Plotly.js с AJAX-обновлением без перезагрузки.
- Симуляция замкнутой системы (дискретная модель), метрики качества
  (перерегулирование, время регулирования, IAE).
- Ручная корректировка Kp/Ti/Td с пересчётом симуляции.
- Экспорт отчётов в PDF (reportlab) и Excel (openpyxl).

## Установка и запуск

Требуется Python 3.10+. Рекомендуется [uv](https://docs.astral.sh/uv/).

### Через uv (рекомендуется)

```powershell
uv sync          # создаёт .venv и ставит зависимости из pyproject.toml
uv run app.py    # http://127.0.0.1:5000
```

### Классический способ

```powershell
# Создание виртуального окружения
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1

# Установка зависимостей
pip install -r requirements.txt

# Запуск
python app.py
```

Приложение откроется на http://127.0.0.1:5000

## Логика работы

1. **Загрузка** — файл проверяется (кодировка UTF-8/CP1251, наличие колонок),
   интерполируется на равномерную сетку (шаг — медианный интервал или задан
   пользователем), фильтруется медианным фильтром (окно 5–7).
2. **Идентификация** — по ступеньке CV методом двух точек (28,3 % / 63,2 %)
   либо аппроксимацией всей записи FOPDT через `scipy.optimize.curve_fit`
   (мультистарт, поддерживаются объекты с отрицательным усилением —
   «обратное действие»); критические параметры Ku/Tu вычисляются из условия
   фазы −180°. При низком качестве аппроксимации (R² < 0,5) модель выдаётся
   с предупреждением на странице результатов.
3. **Настройка** — выбранный метод выдаёт Kp, Ti, Td; для ITAE запускается
   Nelder–Mead минимизация критерия на дискретной симуляции.
4. **Симуляция** — объект интегрируется методом Эйлера с дробными шагами,
   задержка реализована буфером; регулятор — идеальная форма с фильтром
   производной (N = 10) и насыщением выхода 0–100 %.
5. **Экспорт** — отчёты генерируются на лету и отдаются на скачивание.

## Примечания

- Данные хранятся во временных файлах `uploads/`; в cookie-сессии — только
  пути и результаты расчётов (однопользовательский режим).
- Все параметры по умолчанию настраиваются в `config.py`.
